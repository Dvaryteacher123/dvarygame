📚 API Documentation

Base URL

https://dvary-games.onrender.com/api

Authentication

Authorization: Bearer YOUR_API_KEY

Endpoints

GET
/games
Get all available games
curl -H "Authorization: Bearer YOUR_API_KEY" https://dvary-games.onrender.com/api/games
GET
/games/:id
Get a specific game by ID
curl -H "Authorization: Bearer YOUR_API_KEY" https://dvary-games.onrender.com/api/games/123
GET
/plans
Get all available API plans
curl -H "Authorization: Bearer YOUR_API_KEY" https://dvary-games.onrender.com/api/plans
GET
/usage
Get your API usage statistics
curl -H "Authorization: Bearer YOUR_API_KEY" https://dvary-games.onrender.com/api/usage

⚠️ Rate Limits

  • 🔹 BASIC: 100 requests/day
  • 🔹 PRO: 1,000 requests/day
  • 🔹 PREMIUM: 10,000 requests/day

🚫 Error Codes

  • ❌ 401 - Invalid API Key
  • ❌ 403 - API Key Expired
  • ❌ 429 - Rate Limit Exceeded
