# 🎮 DVARY Games Platform

A comprehensive gaming platform with FimiPay payment integration, wallet system, and admin dashboard.

## ✨ Features

- ✅ User Authentication (Email/Password, Google)
- ✅ Game Store (Free & VIP Games)
- ✅ Wallet System with Balance Management
- ✅ FimiPay Payment Integration
- ✅ Admin Dashboard (Complete)
- ✅ Bonus System
- ✅ Notifications
- ✅ Announcement Bar
- ✅ PWA Support
- ✅ Responsive Design
- ✅ Dark Theme with Glassmorphism
- ✅ Search & Filters
- ✅ Download History
- ✅ Analytics & Reports

## 🛠️ Tech Stack

### Frontend
- React 18 + Vite
- Material-UI
- Firebase Authentication
- React Router v6
- React Query
- Framer Motion

### Backend
- Node.js + Express
- Firebase Admin SDK
- Firestore Database
- FimiPay API
- Helmet, CORS, Rate Limiting
